# Calc-Gastos 2.0

Aplicación web sencilla de finanzas personales: ingresos, gastos, categorías, saldo y estadísticas en COP.

Consulta `README-CALC-GASTOS-2.0.md` para conocer el alcance, arquitectura, migración e instalación.

```bash
pnpm install
pnpm test
pnpm dev
```

Guía técnica y recorrido de las funciones principales: [`docs/GUIA-CODIGO-COMENTADO.md`](docs/GUIA-CODIGO-COMENTADO.md).
